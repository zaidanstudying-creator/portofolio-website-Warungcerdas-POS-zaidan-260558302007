# WarungCerdas POS

WarungCerdas POS adalah aplikasi kasir berbasis web untuk membantu operasional warung dan usaha kecil. Aplikasi ini memudahkan pencatatan pesanan dan transaksi sekaligus menyediakan alat untuk mengelola produk, memantau penjualan, dan mengatur operasional toko.

## Fitur

- Kasir dan pencatatan pesanan dengan pembayaran tunai atau QRIS.
- Pengelolaan produk, kategori, topping, dan promo.
- Pengaturan profil dan status toko.
- Dashboard, laporan penjualan, dan ekspor laporan.
- Pencatatan pemasukan dan pengeluaran.
- Pengelolaan akun dengan peran administrator dan kasir.
- Arsip transaksi dan cetak struk.
